I was a teaching assistant for the [IICD Workshop Series: Inferring Cancer Clonality from DNA](https://cancerdynamics.columbia.edu/events/iicd-workshop-series-inferring-cancer-clonality-dna). I prepared example code and a Docker setup for [PhyloWGS](https://doi.org/10.1186/s13059-015-0602-8), [PyClone-VI](https://doi.org/10.1186/s12859-020-03919-2), [SciClone](https://doi.org/10.1371/journal.pcbi.1003665), [MOBSTER](https://doi.org/10.1038/s41588-020-0675-5), and [DECODE](https://pubmed.ncbi.nlm.nih.gov/42367953/) ([materials](https://github.com/dinhngockhanh/IICDWorkshopInferringClonality)).
